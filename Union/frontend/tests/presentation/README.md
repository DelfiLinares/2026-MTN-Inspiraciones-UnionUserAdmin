# tests/presentation

Carpeta destinada a los tests de componentes de presentación (React) del Frontend Administrativo:
reglas de permisos visibles, confirmaciones explícitas, estados de carga/error, distinción visual
de acciones sensibles.

Ejemplos previstos (ver `specs/002-frontend-admin/tasks.md`): `UsuariosPage.test.ts`,
`PublicacionesPage.test.ts`, `ReportesPage.test.ts`, `PromocionPage.test.ts`,
`ConfirmacionesTransversal.test.ts`, `DistincionVisualTransversal.test.ts`,
`EstadosDeCargaTransversal.test.ts`.

> Carpeta creada en el marco de T001 (`specs/002-frontend-admin/tasks.md`). Aún sin contenido:
> los tests concretos se añaden en fases posteriores (T039, T047, T062, T062b, T068, T069–T071).
